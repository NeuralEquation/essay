# EIKEN BODY TRAINER

英作文Bodyの「型＋位置＋論理上の役割」を反復する、小さなオフライン学習アプリです。

公開サイト: [EIKEN BODY TRAINER](https://neuralequation.github.io/essay/)

GitHub Pagesで配信するPWAです。公開サイトでも学習記録はブラウザー内だけに保存されます。

## ホーム画面に追加・オフライン利用

「インストール済み」と表示されて追加できない場合は、[インストール専用ページ](https://neuralequation.github.io/essay/install.html)をChromeの通常タブで開いてください。このページは古い画面キャッシュを使わず、別URLのmanifestで準備します。解消しない場合は、同ページの「インストールできない場合の確認情報」をコピーして確認できます。学習記録を削除する必要はありません。

公開サイトを通信できる状態で開き、「オフラインで使えます」の表示を確認してください。その後は、ページを閉じて開き直してもオフラインで学習できます。

- Android / Galaxy Tab：Chromeのメニュー（⋮）→「アプリをインストール」または「ホーム画面に追加」。アプリ内の追加ボタンが表示される場合は、それも使用できます。
- iPhone / iPad：Safariの共有メニュー→「ホーム画面に追加」。
- PC：Chrome / Edgeのアドレスバーのインストールアイコン。

PWA版は `index.html`、`app.webmanifest`、`sw.js`、`icons/` で構成します。旧manifestは互換用に残しています。GitHub Pagesの `/essay/` 配下だけを対象に、画面・教材・アイコンをキャッシュします。更新がある場合は「最新版に更新」を押すと再読み込みします。学習記録は保持します。更新時は `sw.js` のVERSIONを変更してください。

初回アクセスには通信が必要です。ブラウザーのサイトデータを消すと、オフライン用データと学習記録も消えます。実機でのインストール操作は未確認です。

## 開き方

学習本体のCSS・JavaScript・教材は `index.html` に埋め込んでいます。外部フォント・ライブラリ・APIは使いません。PWAの準備には同じサイトの補助ファイルだけを読み込みます。直接ファイルで開く場合はPWAを登録せず、従来の学習機能を使える構成です。

ローカルHTTPで開く場合は、このフォルダーで次を実行し、ブラウザーで <http://127.0.0.1:5173/> を開いてください。

```powershell
python -m http.server 5173 --bind 127.0.0.1
```

サーバーを停止する場合は、そのターミナルで Ctrl+C を押します。スマホやタブレットへ移す際も、必要なのは `index.html` のみです。AndroidでローカルHTMLを開く方法や保存可否は、ファイル管理アプリ・ブラウザーによって異なります。

## 学習

- A/B/Cのカードを開き、最初に4行の論理の流れを確認します。
- 各行をタップして英文を表示し、再度タップして隠します。
- 「説明」「例文」「言い換え」は、それぞれ独立して開閉できます。
- 「すべて表示」「すべて隠す」「ランダムに隠す」は、その型の4行に適用します。ランダムでは1〜3行を隠します。
- 英文を隠すと詳細も閉じます。全表示やランダム表示では、詳細を一度に開きません。

## テスト

型まるごと3問、文脈付きスロット12問、スロットに紐付いた言い換え11問の計26問です。A型2行目の `S + V` は英文の骨格なので、固定表現の言い換え問題にしていません。

答えを見る前に頭の中で再生し、表示後に「言えた」「怪しい」「無理」を選びます。文脈付きスロットの答えは解答例です。前後の因果がつながれば、一字一句の一致は不要です。意味が変わる代案では、表現と意味の違いを一緒に思い出します。

1セットは10問。種別・型を変更すると、新しい10問を始めます。記録済みの自己評価は保持します。

優先順位は最新の自己評価で決めます。

1. 無理
2. 怪しい
3. 未評価（未学習）
4. 言えた

直前の問題を候補から外し、残る問題の中でこの順に選びます。同じ優先度では直近2問を避け、出題回数の少ない問題を優先します。候補が1問だけの場合は、その問題を反復します。

## 学習記録

ブラウザーのlocalStorageに、問題ごとの出題回数、3段階の評価回数、最新の評価、最終自己評価時刻、連続「言えた」と最高連続数だけを保存します。配色や開閉状態は保存しません。

「学習した問題数」は自己評価済みの問題の種類数、「苦手数」は最新の評価が「怪しい」または「無理」の問題数です。

定着度は、問題ごとに評価履歴を「言えた」100点・「怪しい」50点・「無理」0点で平均し、未学習を0点として全問題で平均します。A/B/Cは各5問（型まるごと＋4スロット）、言い換えは11問を別集計します。

記録は端末・ブラウザー・開き方に紐付きます。HTTPと直接ファイルで開いた場合は記録を共有しません。保存領域が使えない場合や記録が読み込めない場合は画面に通知し、一時的な学習を続けられます。読み込めない記録は、自動で上書きせず明示的なリセットまで残します。

リセットは確認ダイアログの後に、このアプリの記録だけを消します。他のlocalStorageキーには触れません。
